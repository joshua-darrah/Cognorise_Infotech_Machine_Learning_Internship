# House Price Prediction

**Cognorise Infotech — Beginner Project**

Dataset: **Custom synthetic residential property dataset created for this internship project**.

The dataset is intentionally realistic and includes numeric/categorical property features, missing values and duplicate records so the required cleaning workflow can be demonstrated. It is **not** presented as the Kaggle House Prices dataset.

Target: `SalePrice`

## Required deliverable coverage
- Data cleaning and validation
- Exploratory analysis
- Visualisations
- Feature preparation/engineering
- Linear Regression and Random Forest regression
- MAE, RMSE and R² evaluation
- Feature interpretation
- Key insights
- Practical business recommendations

## Run
1. The custom dataset is already included in `data/train.csv`.
2. Run `python train_and_analyze.py`.
3. Or open `notebooks/house_price_prediction.ipynb` and run all cells.
4. Trained models are saved to `models/` and charts/results to `outputs/`.
