# Employee Attrition Prediction

**Cognorise Infotech — Intermediate Project**

Dataset: Kaggle IBM HR Analytics Employee Attrition & Performance

Source: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Target: `Attrition`

## Required deliverable coverage
- Data cleaning and validation
- Exploratory analysis
- Visualisations
- Feature preparation/engineering
- Machine-learning model(s)
- Evaluation metrics required by the internship brief
- Key insights
- Practical business recommendations

## Run
1. Download the specified dataset from the source above.
2. Put the required CSV in `data/`.
3. Open the notebook in `notebooks/`.
4. Run all cells from top to bottom.
5. Trained models are saved to `models/` and charts to `outputs/`.
