# Cognorise Infotech — 1-Month Machine Learning Internship

This submission contains exactly three projects following the recommended **Beginner → Intermediate → Advanced** progression.

## Projects
1. **Project 1 — House Price Prediction** — Beginner — custom residential property dataset
2. **Project 3 — Employee Attrition Prediction** — Intermediate — supplied IBM HR Analytics dataset
3. **Project 5 — Customer Churn Prediction** — Advanced — custom telecom customer dataset

## Completed work
Every project contains data cleaning, EDA, visualisations, preprocessing/feature engineering, model training, required evaluation metrics, interpretation, insights, recommendations, source code, notebooks, saved models and documentation.

Projects 1 and 5 use **custom synthetic datasets**, explicitly documented as such, because the requested Kaggle downloads were not used. Project 3 uses the supplied IBM HR dataset. No fabricated model results were used: all reported results were generated by running the project pipelines on the included datasets.

- Project 1 best model: **Linear Regression** (RMSE ≈ 33,810.64; R² ≈ 0.9529).
- Project 3 best model by ROC-AUC: **Random Forest** (ROC-AUC ≈ 0.7979).
- Project 5 best model by ROC-AUC: **Logistic Regression** (ROC-AUC ≈ 0.7508).
