# Customer Churn Prediction

**Cognorise Infotech — Advanced Project**

Dataset: **Custom synthetic telecom customer dataset created for this internship project**.

The dataset contains customer demographics, tenure, contract, services, charges, support activity and churn labels. Missing values and duplicate records are intentionally included to demonstrate the required cleaning workflow. It is **not** presented as the Kaggle Telco Customer Churn dataset.

Target: `Churn`

## Required deliverable coverage
- Data cleaning and validation
- Exploratory analysis
- Visualisations
- Customer-level feature engineering
- Logistic Regression and Random Forest classification
- Accuracy, Precision, Recall, F1-score and ROC-AUC
- Risk segmentation
- Feature interpretation
- Key insights
- Practical retention recommendations

## Run
1. The custom dataset is already included in `data/WA_Fn-UseC_-Telco-Customer-Churn.csv`.
2. Run `python train_and_analyze.py`.
3. Or open `notebooks/customer_churn_prediction.ipynb` and run all cells.
4. Trained models are saved to `models/` and charts/results to `outputs/`.
